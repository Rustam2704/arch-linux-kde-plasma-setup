# Возможности whitebook на Lenovo (Arch + KDE Plasma)

Что из `~/ai/claude/setup/FEATURES.md` (Xfce + i3 на whitebook) переносится на ноутбук друга с
KDE Plasma 6 на Wayland, и какими средствами. Пометки: **есть** — штатно в Plasma, настроить в «Параметрах
системи»; **виджет** — готовый виджет/расширение; **скрипт** — своя небольшая надстройка;
**нет** — не имеет смысла или невозможно. Ссылки на whitebook — эталон поведения, код оттуда
переносить только идеями: там Xfce/i3, здесь Plasma.

## Сессия и система

| Пункт whitebook | Plasma | Как |
|---|---|---|
| Автологин без выбора сессии, загрузка без меню | есть, уже сделано | SDDM autologin (`/etc/sddm.conf.d/10-autologin.conf`), systemd-boot `timeout 0` |
| Всё объявлено в дереве и ставится одной командой, журнал изменений | скрипт | Тот же подход: git-репозиторий с `~/.config/*rc` и системными файлами + скрипт применения. Plasma хранит настройки в INI-файлах (`kdeglobals`, `kwinrc`, `plasma-org.kde.plasma.desktop-appletsrc`, `kglobalshortcutsrc`), их можно класть в дерево и применять `kwriteconfig6`. Готовые аналоги: `konsave` (AUR, снимки профиля Plasma), `chezmoi`/`stow` для дотфайлов |
| Единая система стиля (theme.json, токены) | скрипт | Своя цветовая схема Plasma (`~/.local/share/color-schemes/Sky.colors`) задаёт цвета всем Qt/KDE-программам сразу; GTK подхватывает через `kde-gtk-config` + Breeze-GTK. Токены нужны только для собственных скриптов |
| HiDPI 1,5× | нет (не нужно) | Экран 1080p на 15,6", масштаб 100 %. При желании 110–125 % в «Дисплей та монітор» |
| Тесты | нет | Не нужны для чужой машины |
| Особенности MacBook (прошивка, Wi-Fi, Fn, вентилятор, камера) | нет | Не применимо. Аналог для Legion: `lenovolegionlinux-dkms-git` (AUR, `-git`) — режимы вентилятора и питания, только по запросу друга |

## Окна как в Windows

| Пункт | Plasma | Как |
|---|---|---|
| Кнопки в шапке (свернуть/развернуть/закрыть) | есть | Декорация Breeze штатно; порядок и размер кнопок в «Вигляд вікон → Декорації» |
| Перетаскивание к краю = половина/развернуть | есть | KWin «Швидке розташування» (quick tiling) через край экрана; в Plasma 6 также раскладки при зажатом Shift (tiling editor, Meta+T) |
| Перетаскивание окна на номер области в панели | виджет | Пейджер Plasma принимает окно, брошенное на номер стола |
| Развернуть с точным возвратом, двойной клик по шапке | есть | KWin штатно |
| Сворачивание, Alt+Tab, Super+стрелки | есть, уже настроено | `kglobalshortcutsrc`; Alt+Tab с превью — «Перемикач вікон» |
| Порядок окон, диалоги над владельцем | есть | KWin делает сам |
| Новые окна рядом с первым, всплывающие плавают | есть | KWin «Правила вікон» для отдельных программ |
| Рабочие области у каждого экрана свои | нет | В Plasma виртуальные столы общие для всех экранов; у каждого экрана свои — только «Activities», это другая модель. Реалистично: общие столы 1–5 + пейджер на каждом экране |
| Панель на втором экране автоматически | есть | Панель клонируется на новый экран вручную один раз, Plasma помнит по экрану; раскладку мониторов помнит kscreen |
| Режим passthrough для RustDesk | нет | В KWin глобальные клавиши перехватываются всегда; частично — правило окна «Ігнорувати глобальні клавіатурні скорочення» для окна RustDesk |
| Автозакрытие окна «Update — Sublime Text» | скрипт | KWin-скрипт на JS (`~/.local/share/kwin/scripts/`), 10 строк |
| Telegram скрыт из дока | есть | Правило окна «Пропускати панель задач» для класса TelegramDesktop |
| Меню избранного с фиксированными областями | есть | Kickoff «Обране» + правила окон «Віртуальна стільниця» для программ; автозапуск — «Автозапуск» в параметрах |

## Панель

| Пункт | Plasma | Как |
|---|---|---|
| Док с закреплёнными, новые окна с края | есть | «Панель задач (тільки піктограми)»; направление роста — штатно слева направо, справа налево нет |
| Полоса областей с цифрами, огонь и пентаграммы Diablo | скрипт (готов: `plasma-port/panel/sky-pager`) | Свой виджет Plasma: цифры шрифтом Diablo, те же кадры огня и пентаграмм, занятые столы светлее; без перетаскивания окна на цифру |
| Индикаторы не сдвигают соседей | частично | Виджеты Plasma фиксированной ширины не гарантируют; для своих индикаторов — виджет `Command Output` с моноширинным шрифтом и заранее заданной шириной |
| Telegram с числом непрочитанных | есть | Значок Telegram в трее показывает счётчик сам |
| Wi-Fi с уровнем | есть | Виджет «Мережі» в трее |
| Пинг «сейчас · медиана» | виджет/скрипт | `plasma-applet-commandoutput` (AUR) + скрипт пинга; либо виджет «System Monitor Sensor» с датчиком сети |
| CPU / RAM / SWAP | есть | Виджеты «Монітор системи» (CPU, память, своп) прямо в панель |
| Погода | есть | Виджет «Погода» (источник в настройках) |
| Батарея с процентами | есть | Виджет «Батарея та яскравість», проценты в настройках |
| Звук с микрофоном записи | есть | Виджет «Гучність звуку», микрофон показывается, когда используется |
| Раскладка EN/RU/UA цветами | частично | Виджет «Розкладка клавіатури»: подпись или флаг; цвет по языку — только своим Command Output |
| Часы семисегментные | виджет | Виджет «Цифровий годинник» + шрифт DSEG7 и размер в настройках; мигающее двоеточие — нет |
| Кнопка выключения | есть | Виджет «Блокування/Вихід» с одной кнопкой |
| Меню Wi-Fi, сеть, звук, календарь, питание | есть | Все стандартные всплывающие окна трея; тест скорости — нет |
| Вуаль подсветки, тултипы не поверх меню | есть | Штатное поведение Plasma |

## OSD и клавиатура

| Пункт | Plasma | Как |
|---|---|---|
| OSD громкости/яркости | есть | Штатный OSD Plasma |
| Попап раскладки по центру | скрипт (готов: `plasma-port/kbd/sky-kbd`) | Штатный OSD Plasma через D-Bus `/org/kde/osdService showText` |
| Alt+Shift EN⇄RU, Ctrl+Shift → UA по отпусканию | скрипт (готов: `sky-kbd`) | evdev (группа `input`) + D-Bus `org.kde.KeyboardLayouts.switchToLayout`; логика аккордов из `osd-daemon` whitebook |
| Звуки клавиш Diablo | скрипт | Та же служба (слушает клавиши, играет wav) |
| Горячие клавиши в любой раскладке | есть | KWin/kglobalaccel работают по кодам клавиш |
| Медиаклавиши | есть | Штатно |
| Скриншоты Print / Super+Shift+S | есть, уже настроено | Spectacle |
| Шпаргалка клавиш | нет/скрипт | В Plasma нет; окно «Скорочення» в параметрах или свой rofi-подобный список |
| rofi (запуск, команда, окна) | есть | KRunner (Meta+R/Alt+Space) делает все три; rofi на Wayland не работает |
| Ctrl+Shift+Esc — btop | есть, уже настроено | «Системний монітор» Plasma; btop в терминале — ярлык на `konsole -e btop` |

## Фон и эффекты

| Пункт | Plasma | Как |
|---|---|---|
| Фон-звёзды | виджет | `sky-stars` — X11-окно, на Wayland не работает. Варианты: обои «Smart Video Wallpaper» (видео звёзд, дорого по CPU) или чёрный цвет + статичная картинка звёзд |

## Итог по приоритетам для Codex

1. **Штатно, только настроить** (час работы): тема и цвета, панель сверху с виджетами (пейджер,
   монитор системы, погода, батарея, звук, раскладка, часы, выключение), правила окон, клавиши,
   Dolphin, Spectacle, KRunner, эффекты без размытия.
2. **Перенести скриптами с whitebook** (по одному, каждый отдельная служба `systemd --user`):
   переключатель раскладок + OSD + звуки клавиш (`sky-kbd`, готов), `netqd` + индикатор пинга
   (Command Output, готов), `light-year`.
3. **Отказаться**: области у каждого экрана свои, passthrough, HiDPI, Firefox-лимиты, MacBook-вещи,
   мигающее двоеточие в часах, док справа налево, `sky-stars`, touchegg (X11).
