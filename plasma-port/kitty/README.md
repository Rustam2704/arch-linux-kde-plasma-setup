kitty как на whitebook: цвета темы, Ctrl+C/Ctrl+V в любой раскладке, правый клик глушится,
Ctrl+клик по пути открывает файл (kate) или папку (dolphin), средняя кнопка — меню пути.
Файлы: kitty.conf → ~/.config/kitty/kitty.conf, open-click.py → ~/.config/kitty/open-click.py,
open-path → ~/.local/bin/open-path (chmod +x). Пакеты: kitty (стоит), kate, dolphin (стоят).
